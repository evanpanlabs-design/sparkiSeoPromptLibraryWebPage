# 针对 [百度] [文心一言 AI产品] 的简历项目描述

---

## 项目概览

在视界引擎公司 AI 增长产品实习期间，我参与了短视频深度解析与 AI 内容策略体系的构建，主导设计了基于多模态大模型的 18 维视频内容分析框架；独立搭建了 Sparki AI Prompt 库平台管理Agent，实现在 Twitter 采集高质量 AI 视频生成 Prompt 并转化为产品SEO网页。

---

## 项目一：短视频深度解析与AI内容策略体系

**一句话总结**：作为增长产品实习生，主导构建了基于多模态大模型的 18 维视频内容分析框架，支撑 AI 视频混剪产品的内容营销与用户教育。

**核心亮点**：

- **18 维内容分析框架**：设计涵盖叙事结构（开篇钩子、三段式叙事、情绪共鸣点）、视觉美学（照明氛围、构图平衡、色彩生动度）等维度的评估体系，为产品建立内容质量评估标准
- **结构化 Prompt 设计**：通过 JSON Schema Prompt 引导多模态大模型输出标准化分析结果，实现视频特征的规模化自动提取；对 Prompt 结构和输出质量有精准的判断能力
- **Multi-Agent 自动化链路**：基于 LangGraph 状态机搭建"视频抓取→多模态分析→特征提取→内容生成"的完整闭环，单条视频处理效率提升 10 倍；积累了定义 Agent 协作流程与跨模块协作的经验

---

## 项目二：Sparki AI Prompt 库平台

**一句话总结**：独立开发了从 Twitter 采集高质量 AI 视频生成 Prompt 并发布到 GitHub Pages 的全栈平台。

**核心亮点**：

- **Prompt 评测体系**：设计了 Specificity / Visual Detail / Novelty / Generatability 4 维度评分体系（权重 25/30/20/25%），低于 0.4 分的内容自动过滤，采集 131 条高质量 Prompt，入库率约 40%
- **语义搜索实现**：使用 Gemini embedding API 生成 768 维向量，存入 SQLite BLOB，搜索时通过余弦相似度排序返回 top-k 结果，将散落的 Prompt 结构化供创作者检索
- **全流程自动化**：基于 LangGraph ReAct 架构封装 12 个独立 Skill（爬虫/评分/图生成/发布等），用户说"跑全程"即可自动串起完整 Pipeline，独立完成从爬虫到 GitHub Pages 部署的全部工作
