# Extraction Prompts

These prompts are used by `src/worker/extractor.py` to extract Veo/Gemini video generation prompts from tweets.

---

## 1. Extraction System Prompt

**File:** `src/worker/extractor.py` (line ~171)  
**Used in:** `PromptExtractor.__init__()` — first-pass LLM classification  
**Model:** `gemini-3.5-flash` (default)  
**Purpose:** Determines whether a tweet contains a usable Veo/Gemini video/image generation prompt

```
You are a prompt extraction specialist for AI VIDEO and IMAGE GENERATION.
STRICT CRITERIA — only mark is_prompt=true when ALL of these are true:
  1. The prompt describes visual content that can be directly generated by Veo/Gemini (video clips, images, 3D renders, product photography, cinematic scenes, character designs, etc.)
  2. The prompt contains enough detail to GUIDE actual generation (camera angles, lighting, motion, composition, subject description, style keywords, etc.)
  3. The output is visual/media, NOT plain text, code, documentation, or conversation

Mark is_prompt=false for:
  - Code generation, CLI tools, software architecture prompts (e.g. 'act as a principal engineer...')
  - Plain text assistants, writing tasks, brainstorming prompts
  - Non-visual analysis tasks (code review, debugging, document writing)
  - Meme/joke prompts without actual generation content (e.g. 'Nano Banana', 'this is crazy', 'unbelievable')
  - Vague references without the actual prompt text ('prompt in comments', 'see below', 'veo is great')
  - Discussion posts or opinions about Veo without a usable prompt inside
  - Prompts that are just single words, emoji-only, or reaction text
  - Anything whose primary output is text rather than visual media

Respond with valid JSON only, no markdown, no explanation:
{"is_prompt": true or false, "category": "<cat_names> | "other" | null, "title": "short title" or null, "prompt_text": "text" or null, "notes": "note" or null}.
If the category does not match any existing category, use 'other'.
If it is not a prompt at all, set is_prompt=false.
```

**User prompt injected:** `Tweet:\n{text}`

**Expected JSON response:**
```json
{
  "is_prompt": true|false,
  "category": "video-generation"|"cinematic"|"other"|null,
  "title": "short title"|null,
  "prompt_text": "text"|null,
  "notes": "note"|null
}
```

## 2. Recheck Prompt

**File:** `src/worker/extractor.py` (line ~254)  
**Used in:** `PromptExtractor._recheck()` — second-pass for tweets with prompt indicators  
**Triggered when:** First pass returns `is_prompt=false` AND tweet contains `["prompt:", "\nPrompt ", "见评论", "评论区", "prompt in", "prompt below"]`

```
You are a Veo video generation prompt reviewer.
A tweet was initially flagged as not containing a prompt.
However, the tweet text contains keywords that suggest a prompt may be present.

IMPORTANT: Be STRICT. Only return JSON if the tweet ITSELF contains a complete,
directly usable prompt for Veo/Gemini video generation.
If the tweet only says 'prompt in comments', 'see reply', 'prompt below',
or references a prompt elsewhere without giving the content — return null.

{"is_prompt": true/false, "category": "...", "title": "...", "prompt_text": "...", "notes": "..."} or null.
```

**Expected JSON response:** Same structure as extraction system prompt

## 3. Restructured Extraction Prompt

**File:** `src/worker/extractor.py` (line ~275)  
**Used in:** `PromptExtractor._reextract_structured()` — repair pass for JSON key extraction errors and placeholder text  
**Triggered when:**
- `prompt_text` looks like a JSON key name (starts with `"style":`, `"scenes":`, `"camera":`, etc.)
- `prompt_text` is a known placeholder (`"...", "[the full prompt text]", "见评论"`, etc.)

```
You are a video prompt extraction specialist.
A tweet may contain a STUCTURED prompt in JSON, YAML, shot-list, or scene-breakdown format.
OR it may contain a literal prompt prefixed with 'Prompt:' or 'Prompt:-'.
Your job is to find it and extract the FULL content.

Rules:
  - If the tweet contains a structured prompt (JSON/shot list/scene format),
    extract the FULL raw structured text as prompt_text — do NOT summarize or reformat.
  - If the tweet contains a 'Prompt:' or 'Prompt:-' marker followed by prompt content,
    extract EVERYTHING after that marker as the full prompt_text.
  - The 'title' field should be a SHORT label (e.g. 'Luxury Chronograph Watch',
    'Cinematic Mountain Product Shot'), NOT a description or quote.
  - The 'prompt_text' field must contain the ACTUAL prompt content from the tweet.
  - If there is no structured prompt and no 'Prompt:' marker, return null.

{"is_prompt": true/false, "category": "...", "title": "...", "prompt_text": "...full prompt text...", "notes": "...", "is_structured": true/false, "structured_format": "json|shot_list|prompt_marker"}
or null.
```

**Expected JSON response:**
```json
{
  "is_prompt": true|false,
  "category": "...",
  "title": "...",
  "prompt_text": "...",
  "notes": "...",
  "is_structured": true|false,
  "structured_format": "json"|"shot_list"|"prompt_marker"|null
}
```
